# История изменений

## 0.3.2 — 2026-11-22

- Иконки нижней панели выровнены по центру подписей.
- Главная страница содержит одно поле для поисковых запросов и адресов, историю поиска и папки закладок.
- Панель загрузки различает текущее медиа, источник и ожидаемый результат. Смена ролика обновляет открытый список.
- Исправлен вылет при подтверждении загрузки. В очереди отображаются причины распространённых ошибок сети и обработки потока.
- Проверены сборка, Android Lint, тесты Java/C++ и переключение медиа на физическом устройстве. Тестовый файл сохранён из GeckoView в системную папку загрузок.
