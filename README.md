# Stream Browser

Android-браузер на GeckoView со встроенным поиском медиа и фоновой загрузкой. Интерфейс использует Material 3 Expressive, а нативное ядро на C++ определяет тип потока и рассчитывает параллельные диапазоны загрузки.

**Текущая версия** — [0.3.2, предварительный релиз](https://github.com/FoxCoderGit/stream-browser/releases/tag/v0.3.2). В разделе Assets находится APK для Android 10 и новее на ARM64 и x86-64. Это отладочная сборка для тестирования.

## Возможности

- Минималистичная главная страница с поиском Google, локальной историей запросов и папками закладок.
- Меню «Медиа» показывает текущее видео, подтверждённый источник и ожидаемый результат. При смене видео обновляется и уже открытое меню.
- Прямые файлы загружаются в фоне. Поддерживаются параллельные диапазоны и возобновление, если сервер предоставляет стабильный ETag.
- HLS, DASH и загрузка по адресу страницы обрабатываются через yt-dlp и FFmpeg. Доступность потока зависит от сайта и способа воспроизведения.
- Файлы сохраняются в `Download/StreamBrowser`. Для очереди загрузок контекст сессии хранится локально в зашифрованном виде.

## Сборка

Нужны JDK 21, Python 3, Android SDK 37.2, NDK 27.2.12479018 и CMake 3.22.1. Путь к Android SDK можно указать через `ANDROID_HOME` или файл `local.properties`.

```powershell
python tools/prepare_gecko.py
python tools/prepare_runtime.py
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK появится в `app/build/outputs/apk/debug/`. На Windows с кириллицей в пути используйте `tools/build.ps1`. Скрипт собирает проект во временной папке с латинским путём и возвращает APK в `artifacts/`. Команды для JNI-тестов и сведения о зависимостях есть в [BUILDING.txt](BUILDING.txt).

## Как устроен проект

| Путь | Назначение |
| --- | --- |
| `app/src/main/java/` | Интерфейс браузера, закладки, фоновые задания, транспорт и сохранение файлов |
| `app/src/main/cpp/` | Классификация медиа и расчёт диапазонов загрузки |
| `gecko/` | Патч GeckoView, наблюдение за плеером и происхождение двоичных зависимостей |
| `tools/` | Подготовка зависимостей, сборка и проверка APK |

Патч выполняется внутри GeckoView. Для сайтов, где плеер выдаёт только `blob:` и связь с сетевым потоком не подтверждена, доступно отдельное действие «Загрузить по адресу страницы». Загрузка потоков с DRM не поддерживается.
